## ⚡ Portfolio Highlights

- **Interactive 3D Elements:** Built with **Three.js** and **React Three Fiber (@react-three/fiber, @react-three/drei)** featuring interactive 3D assets and dynamic particle star fields.
- **Micro-Interactions & Tilt Physics:** Seamless transitions powered by **Framer Motion** and interactive 3D perspective card tilting via **react-tilt**.
- **Dark Glassmorphism Design:** Modern cyberpunk-inspired aesthetics styled with **Tailwind CSS**, backdrop blurs, and responsive grid layouts.

## ⚙️ Local Development

Follow these steps to run the portfolio on your local machine:

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/skittermonster/ethan-portfolio.git
   cd ethan-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173/ethan-portfolio`.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages:**
   ```bash
   npm run deploy
   ```
